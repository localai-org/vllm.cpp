(`tests/vllm/models/test_opt_paged_engine.cpp`, "CUDA + Metal + Tenstorrent,
SACRED") selects the device through the platform seam. With
`VLLM_CPP_OPT_MODEL_DIR=/mnt/models/opt-125m-bf16-st` (materialized bf16
safetensors checkpoint) the engine loaded and selected device type 6
(TENSTORRENT), then:

```
./tests/vllm/models/test_opt_paged_engine.cpp:144: ERROR: test case THREW exception:
vt: tenstorrent kQkvSplit: out shapes must be [T, *] at ./src/vt/tenstorrent/tenstorrent_ops.cpp:1437
```

followed by a SIGSEGV (exit 139, ~9 s wall). The golden set itself read clean
(K=5, 0 multi-valued cells, deterministic -> strict bar). This is a named
refusal: the TT `kQkvSplit` op rejects OPT's output shape. Not hacked around,
per instructions. 960 MB peak RSS.
