## Red results and corrections

The actual legacy build rejects unguarded WMMA namespace aliases, BF16 fragment
aliases, `tanh.approx` below sm_75, DP4A below sm_61, nanosleep below sm_70,
and native EXL3 tensor instructions below sm_80. CUDA 12.4 also exposes the
incorrect 12.2 guard around `cudaGetDriverEntryPointByVersion`, introduced in
CUDA 12.5. [NVIDIA CUDA 12.5 API](https://docs.nvidia.com/cuda/archive/12.5.0/cuda-runtime-api/group__CUDART__DRIVER__ENTRY__POINT.html).
The [initial compile log](compile-red.log) records the first failures.

The existing cuBLASLt BF16 path already executes correctly on Pascal. A
72-workload registered-op probe passed before changes. Nsight Systems traced
actual GPU `gemv2N_kernel`, `gemv2T_kernel_val`, and `magma_sgemmEx_kernel`
with BF16 storage and float compute. [Full template names](bf16-baseline-trace.txt).
This is CUDA-core arithmetic, not native BF16 hardware. No replacement for
that working path was added.

The representative production probe then failed on registered
`vt::BatchedMatmul`: F32 inputs, BF16 output, batch 3, M=17, K=31, N=13,
`CUBLAS_STATUS_NOT_SUPPORTED`. [Runtime red](matmul-red.log).
Only that dtype lane below sm_80 gets a tiled CUDA fallback. BF16 storage
and all existing newer-GPU dispatch remain unchanged.

## Focused green and mutation

`test_cuda_legacy_matmul` checks 28 registered CUDA matrix workloads. It covers
SmolLM2-135M shapes with hidden 576, intermediate 1536, vocabulary 49152,
M=1,16,128, BF16 and F32 outputs, padded BT activations, padded batched
inputs and outputs, and F32-to-BF16 batched output. Boundary and interior
values are checked against independent exact dyadic products. Host reference
fallbacks are refused by the test. [Green output](matmul-green.log).

Removing the production fallback call in a scratch source restores the
`CUBLAS_STATUS_NOT_SUPPORTED` failure. [Call-site mutation](matmul-callsite-mutation.log).
The checked-out source is unchanged by that scratch mutation.

`test_cuda_legacy_intrinsics` compiles for sm_60, even on sm_61 hardware.
It compares 4096 signed and unsigned byte products against scalar host
arithmetic, including accumulator wraparound. Replacing the signed fallback
result with its input accumulator fails case 1. [Mutation output](dp4a-signed-mutation.log).
The exact sm_60 byte products come from pinned llama.cpp
`ggml/src/ggml-cuda/common.cuh:712-753`. Native DP4A remains selected at sm_61.

## Reproduce

```sh
cmake -S . -B /tmp/lumen-build-legacy -G Ninja -DVLLM_CPP_CUDA=ON \
  '-DVLLM_CPP_CUDA_ARCHITECTURES=60;61;70' -DVLLM_CPP_BUILD_TESTS=ON
cmake --build /tmp/lumen-build-legacy --target test_cuda_ops \
  test_cuda_quant_dot test_cuda_backend test_cuda_legacy_intrinsics \
  test_cuda_legacy_matmul test_cuda_legacy_capi -j4
flock "${GPU_LOCK:-$HOME/gpu.lock}" ctest --test-dir /tmp/lumen-build-legacy \
  -R '^test_cuda_(legacy_intrinsics|legacy_matmul|ops|quant_dot|backend)$' \
  --output-on-failure
```

The public ABI harness requires a real artifact and pretokenized prompt:

```sh
flock "${GPU_LOCK:-$HOME/gpu.lock}" \
  /tmp/lumen-build-legacy/tests/test_cuda_legacy_capi MODEL.gguf PROMPT.i32 16 3
```

It loads one engine through `vllm_engine_load`, explicitly requests device 2,
uses greedy `vllm_complete_tokens`, ignores EOS, and prints every output ID.
The fixed context is 256 tokens, block size 16, block count 16, concurrency 1.
A missing artifact is a skipped external gate, never a synthetic substitute.

## Public attention reachability

The synthetic GGUF fixture supplements the real-checkpoint gate. It is not a
published model. CPU and explicit CUDA complete four identical greedy token IDs
for prompt lengths 1, 16, and 37. The callback captures all finite logits;
CUDA must not use the host reference tier. [Output](public-green.log).

The original public load failed because FLASH_ATTN correctly rejects compute
6.1. [Public red](public-load-red.log). The separate CUDA_LEGACY descriptor
reaches existing portable attention through the shared runner and op table.
Removing its registrar fails public load again. [Mutation](public-registrar-mutation.log).
Removing its priority selection fails three host capability cases.
[Priority mutation](priority-mutation.log). The unchanged host gate passes
22 cases and 104 assertions. [Host gate](attention-host-green.log).
The existing FLASH_ATTN minimum and newer architecture priorities are unchanged.

## SiLU intermediate dtype

Pinned vLLM `csrc/libtorch_stable/activation_kernels.cu:30-44,165-180` returns
the input scalar type from scalar and packed SiLU before multiplication.
The source fetched at the recorded revision has SHA256
`032bff4a24ea81bafaea5fcc326514a241e31faa24f082d7652cf8b62a4a764c`.
The legacy kernel now rounds the intermediate accordingly. Newer GPU behavior
is unchanged. The existing CUDA operator suite passes all 446 assertions.
[Green](ops-green.log). Removing the legacy rounding restores both failing
BF16-to-F32 cases. [Mutation](silu-mutation.log).
